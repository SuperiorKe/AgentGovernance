# Quick Start — Informal Economy Intelligence Agent

## Installation (30 seconds)

1. Copy the `.claude/` folder into any project directory where you want to run research
2. That's it. Claude Code auto-discovers sub-agents in `.claude/agents/`

---

## Run a Research Brief

Open Claude Code in your project directory and type:

```
Use the informal-economy-intel agent to research [your market here]
```

### Starter Queries for SuperiaTech Projects

**For Mama Mboga expansion:**
```
Use the informal-economy-intel agent to research informal food vendors 
in Mombasa and Kisumu — how do their challenges differ from Nairobi vendors?
```

**For Afrimall:**
```
Use the informal-economy-intel agent to map the Jua Kali artisan sector 
in Nairobi — how do they currently find customers and manage orders?
```

**For new project scoping:**
```
Use the informal-economy-intel agent to research boda boda riders 
in Nairobi — pain points around daily earnings tracking and fuel costs.
```

**For investor/grant prep:**
```
Use the informal-economy-intel agent to research the size and growth 
of the informal retail sector in Kenya — statistics, reports, funding activity.
```

---

## Output Location
All briefs are saved to: `./outputs/[market-slug]-intel-brief.md`

---

## Pro Tips

- **Narrow the query = better brief.** "Women fish vendors in Kisumu" beats "fish vendors in Kenya"
- **Chain with your Job Application Agent.** Run a brief → paste the whitespace section into a cover letter to show product thinking
- **Run quarterly.** Markets shift. A brief from 6 months ago may miss a new competitor
